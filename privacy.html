One More Move privacy notice

Effective date: Draft for pre-release testing

This version of One More Move has no account, advertising, analytics, social login, cloud save, or third-party tracking SDK. It does not transmit gameplay or personal information to the developer.

Information stored locally

The game stores settings, completed-puzzle counts, best score, daily streak and daily scores in browser or app-local storage. An unfinished circuit may also be stored locally so it can be resumed. This information stays on the device unless the operating system includes it in a device backup.

Control and deletion

Use Reset progress on the game menu to erase saved game information, or clear the site's/app's storage. Uninstalling the packaged app normally removes local app data, subject to operating-system backup and restore behaviour.

Network access

The public web version must download its files from its hosting provider, which may process ordinary request information such as IP address, browser details and request time for security and delivery. The planned bundled Android version will contain the game assets and will not require gameplay network access.

Future changes

If analytics, advertising, cloud saves, purchases, or other data processing are introduced, this notice and the applicable store disclosures must be updated before release.
